STRUCTURE RULES · v7.1 结构规则（主人定稿）

① 外壳唯一「✓ 已完成 · 执行了 x 个工具 · 用时」全消息最外部唯一一行——工具数与用时只在结束后出现。
② 内部合并外壳展开后，「执行了 x 个工具」是内部文本与文本之间的工具组聚合行——一轮的多个工具不逐个铺开。
③ 两级明细内部合并行再点击 → 每步明细（动词 + 参数 + 每步耗时）；思考保持独立折叠行。
④ 中间文本平铺外壳展开区内的中间叙述文本平铺可见——工作叙事保留，只折叠细节。
⑤ 执行中无进度未结束无总量 → 不做 N/M；执行感 = 当前阶段实时切换（思考中字数增长 / 动词 + 参数跟随 running 工具变化）。
⑥ 思考的三个时点执行中：外壳行「思考中 · N 字…」实时增长（LLM 推理阶段）；展开后：内部第一行「▸ 思考过程 195 字 · 2.1s」折叠，点击看全文；最终回答不受影响。
