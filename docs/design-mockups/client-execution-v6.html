FIVE PRINCIPLES · 助手产品执行过程的五原则（对照 ChatGPT / Claude / Manus）

① 一行摘要收起态说清「状态 + 步数 + 总用时」——用户不展开也能感知成本（Claude「Thought for 12s」同构）。
② 轻提示running = spinner + 当前动词，无大色块；琥珀只留给步骤行的运行中标记，不铺满卡片。
③ 技术细节退后命令/路径/全文只在行尾 mono 截断示意或展开层限高滚动——终端用户读的是「在做什么」。
④ 完成即收起过程卡完成后自动折叠为一行，点击头部随时回看——过程是叙事的脚注，不是主角。
⑤ 步骤级耗时展开态每步右侧 mono 自身耗时（Manus 模式）——「慢在哪一步」一目了然；数据源为 per-tool 计时。
DATA DEPS · 步骤级耗时需要 per-tool duration（ToolRun 计时，当前仅有轮级 llm/tool 拆分——设计先行，数据后补）· 总用时 = done usage llm+tool 毫秒拆分（本轮已修通 ext 历史链路）· 步数 = 工具调用数
