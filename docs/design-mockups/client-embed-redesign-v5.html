IMPLEMENTATION NOTES · v5 相对 v4.5 的增量与裁剪清单

① 品牌地基（v4.5 有稿未落地，本稿强制）
暖纸白 #FAFAF7 消息区落地（现值 #F7F8FA 冷灰，必须换）；衬线斜体字标 MEPER Agent 进 header 与抽屉头；logo 一律单色——浮窗衬线 M / 抽屉靛蓝方章，废弃蓝绿渐变 3D 图；amber 琥珀只归确认卡。
② 形制换制（脱离 ant-bubble 范式）
agent 消息 = 通栏书写流墨字（无气泡容器）；用户消息 = 右贴边靛蓝批注贴（面板唯一大色块）+ 姓氏圆点头像；过程卡收起一行「已完成 · 用时 X」，展开为 mono 步骤行。
③ 交互定稿（抽屉化 + 裁剪清单）
☰ 汉堡为侧栏唯一入口（拖宽面板不再联动，已实施）；抽屉内 删除主题切换、删除会话文件入口（apikey 模式）；底部用户区 = 头像 + 名字 + 撤销授权描边胶囊。
助手选择器 · 按绑定数量分段（切换是低频操作，会话列表才是抽屉主角）
1 个 → 整节不渲染；2–4 个 → 纵向展开（一眼全见，见场景②）；≥5 个 → 收纳为「当前助手」行，点击弹出纸卡列表（同纸语言自绘，不用 SaaS 下拉框）。
