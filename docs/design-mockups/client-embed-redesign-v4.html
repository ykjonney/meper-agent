DESIGN NOTES · 与 studio 的同源与分野

同源（品牌基因不可丢）暖纸白底、墨色文字、衬线斜体字标、靛蓝 #2B4A9E 唯一品牌彩、实色 + 1px 纸线 + 单层浅影——与 studio 纸墨 v4 完全同一套语言。
分野（client 的对话纸个性）面板是一张对话纸：agent 回复是纸上墨字（无气泡书写流），用户的话是页边墨色批注贴（右上折角，贴边形态）——书写与批注的隐喻替代 SaaS 气泡。
Signature（记忆点·修正）印章归位确认卡：助手是高频随手工具，发送钮回归轻盈靛蓝小方；「盖章」意象留给确认卡主选项（批准=盖章，语义完美）——隐喻用在语义正确的地方。
